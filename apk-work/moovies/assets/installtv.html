Allow installation from Downloader

Amazon Fire TV / Firestick

  • Open Settings › My Fire TV › Developer Options.
  • Select Install unknown apps and enable it for Downloader.
  • If you see “Apps from Unknown Sources”, turn it on and continue with the install.

Android TV / Google TV

  • Go to Settings › Security & restrictions › Install unknown apps.
  • On some devices: Settings › Apps › Special app access › Install unknown apps.
  • Enable permission for the Downloader app, then return to finish installing.
